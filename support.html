أي سؤال أو مشكلة أو اقتراح، نسعد بالتواصل: nahlah@nahlah.io

أسئلة شائعة

استرجاع الاشتراك على جهاز جديد؟
من صفحة «تقدّمي» ← «استرجاع المشتريات».

إلغاء الاشتراك؟
من إعدادات الجهاز ← Apple ID ← الاشتراكات ← صفا.

عدّاد شاشة القفل ما يظهر؟
من إعدادات الجهاز ← صفا ← تفعيل «الأنشطة المباشرة».

إضافة أداة صفا للشاشة الرئيسية؟
ضغطة مطوّلة على الشاشة الرئيسية ← زر «+» ← البحث عن «صفا».

اختصار Siri لبدء التركيز؟
في تطبيق «الاختصارات»: إجراء «فتح عنوان URL» بالرابط safa://next.

Support

Questions, issues or ideas: nahlah@nahlah.io

FAQ

Restore on a new device?
Progress → Restore purchases.

Cancel?
Settings → Apple ID → Subscriptions → Safa.

Lock-screen timer not showing?
Settings → Safa → enable Live Activities.

Add the widget?
Long-press the Home Screen → “+” → search “Safa”.

Siri shortcut to start focusing?
In Shortcuts, add “Open URL” with safa://next.
